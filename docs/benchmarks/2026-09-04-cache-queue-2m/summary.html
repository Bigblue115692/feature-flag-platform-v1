Cached evaluation + queued audit

Two-minute load ramp · 6 Gunicorn workers · Redis flag cache · durable Celery audit queue

What the run proved: 500 and 1,500 eval/s were handled cleanly. During the ramp toward 3,000/s, Nginx exhausted local source ports because it did not reuse upstream connections. This test found a proxy networking bottleneck—not the endpoint’s final capacity.

Key findings

  • Measured average: 1,784 completed HTTP attempts/s across the entire run, including failures.
  • Correctness held: rollout participation was 24.90% and targeting participation was 100%.
  • Auditing stayed asynchronous: the queue accumulated about 8,875 events under load, then drained to zero.
  • Next experiment: enable Nginx upstream keepalive and rerun the identical scenario before changing Django worker count again.
